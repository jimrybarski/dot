# Variable names

- Hash maps should use the naming convention `value_by_key`.

# File names

- Use kebab-case.
- Files and directories that need to contain dates should use the YYYY-MM-DD format. For timestamps, use YYYY-MM-DDTHH:MM:SSZ (ISO 8601, UTC).
